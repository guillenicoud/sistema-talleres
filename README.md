# Sistema de Gestión de Talleres - Secretaría de Juventud

## Descripción

Sistema informático desarrollado para la Secretaría de Juventud con el objetivo de administrar talleres, alumnos y talleristas, centralizando la información y facilitando la gestión de las actividades ofrecidas a la comunidad.

## Objetivos

* Gestionar alumnos.
* Gestionar talleres.
* Gestionar talleristas.
* Administrar horarios y días de cursada.
* Registrar asistencia.
* Generar reportes y estadísticas.

## Tecnologías Utilizadas

### Frontend

* Angular 15
* TypeScript
* Bootstrap

### Backend

* Node.js
* Express

### Base de Datos

* MySQL

## Funcionalidades Implementadas

* Gestión de alumnos.
* Gestión de talleristas.
* Gestión de talleres.
* Gestión de detalle de talleres.
* Dashboard principal.

## Funcionalidades Pendientes

* Registro de asistencia.
* Reportes.
* Estadísticas.
* Exportación de información.
